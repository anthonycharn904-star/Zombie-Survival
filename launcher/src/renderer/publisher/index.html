    5Mise en ligne

    « Publier pour tous les joueurs » envoie la version sur GitHub, qui sert seulement d'entrepôt : les launchers des joueurs la trouvent, la vérifient et l'installent seuls à leur prochain démarrage. Vous n'avez rien à faire sur le site de GitHub.

    Reliez une seule fois ce launcher à votre dépôt GitHub. Ensuite, publier se fait en un clic, d'ici.

    1. (connecté à votre compte GitHub).
    2. Token name : Zombie Survival launcher · Expiration : la plus longue proposée · Repository access : Only select repositories → Zombie-Survival.
    3. Permissions → « Add permissions » → tapez Contents et cochez-le. Sur la ligne Contents qui apparaît, changez Read-only en Read and write (la ligne Metadata s'ajoute seule). Puis « Generate token » et copiez le jeton.
    4. Collez-le ici. Il reste chiffré par Windows sur ce PC et ne sert qu'à publier. Ne le donnez à personne.
